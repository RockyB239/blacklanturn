# Native snapshot artwork repair

Confirmed root cause: native helper artwork is image:// wrapped and percent-encoded. The display snapshot sanitizer accepted direct HTTPS only and stripped all images. Live Mac screenshots showed blank title-only cards and hero, while provider data carried landscape, poster, fanart and logo images. Both public and Home disk snapshots were affected. Earlier card-count speed gates did not prove visual readiness.

Controller107 accepts a single validated native wrapper and preserves its exact original image-cache key. The decoded origin remains HTTPS image.tmdb.org only, without credentials, query, fragment or transform parameters. Direct approved HTTPS remains supported. Display snapshot format2 invalidates broken old format1 caches. User settings, authorizations and playback logic are unchanged.
