# Controller 0.1.105 private performance candidate

Private Build 1.1.41 revision 3 / Controller 0.1.105 / unchanged Installer 1.0.44 was applied through the existing transactional in-place updater on Fire Stick, then Mac and Apple TV. Public publication was not performed. The exact 530 controller files match `controller-source/manifest105.json` on all three devices; individual settings, authorizations and platform workarounds remain preserved.

## Confirmed causes

- Public display snapshots rejected current genre/date/keyword filters and their Next cards. Strict typed validation now accepts known public filters while retaining private/account/search/signed-query exclusions.
- Initial YouTube account discovery invalidated the independently scoped TMDb artwork cache just loaded at startup. Initial discovery now preserves it. Actual account switches and disconnects still invalidate owned session results.
- Background refresh now enriches selected-title metadata as well as watch state without rebinding visible cards, changing membership or moving focus. The same metadata survives feedback repaint.
- Sanitized country and vote metadata remain available for existing anime and hidden-gem eligibility filters.

The existing 48-row / 80-item / 2 MiB / 15-minute display-cache budget is unchanged. No new polling, provider fan-out or recommendation requests were introduced.

One initial Mac warmup missed its first asynchronous Down; ordinary Input.Down recovered immediately. Its unchanged full rerun, subsequent fresh-reopen comparison and fast-input tests passed. The initial Apple preview test had an invalid Context-menu predicate; correcting the test made the same-source preview run pass. These records are retained rather than counted as provider latency or claimed as product fixes.
