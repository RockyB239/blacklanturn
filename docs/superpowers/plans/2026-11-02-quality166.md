## Global Constraints

## Review Focus
- Same release ID with refreshed proof metadata: validated remote/cache wins; owned patches and receipt still required.
- Offline, bad cache or wrong feed: bundled fallback survives without resetting preference/seen state.
- Pending background row during rapid navigation: foreground cannot wait behind speculative work or receive stale focus/results.
- Preview/playback/modal dialog/account invalidation: background preparation yields, memory stays bounded.
- Test cleanup: concurrent/unproven user history is never removed; exact pre-existing events retained.
