# Managed add-on manual update protection

User goal: ordinary Kodi Check for updates / Install all updates must preserve the reviewed BlackLanturn reliability and playback patches without requiring a user to reapply files. Ordinary add-ons must remain updateable. Preserve settings/authorizations and Fire Stick isolation.

Reproduction: native Mac Kodi21.3 Install all updates replaced Helper6.17.9 with6.18.1 and Umbrella6.7.92 with6.7.97 despite per-addon disabled-auto-update rules. Seven source-session functions vanished; 12 read-only source-contract checks failed. Settings/accounts/layout stayed unchanged. Native Home/YouTube1080p/Back/progress continued working. Do not mistake a successful Home for preserved source behavior.

Design: keep current IDs, playback/source-selection code, historical manifests, platform variants and automatic-update rules. Add a reviewed native version epoch for the four managed add-ons, using Kodi21 CAddonVersion semantics: 1:<upstream>+blacklanturn.1. A standard epoch0 upstream update will not qualify as an upgrade. Later reviewed managed releases advance within epoch1. Explicit manual replacement/downgrade is outside this automatic/bulk-update guarantee. No background repatching worker, polling or browsing requests.

The installer verifies exact metadata transformation and exact code separately. Existing historical source manifests remain immutable; only exact reviewed managed XML and the coupled internal-version adapter hashes normalize to their original hashes. The complete protected Umbrella tree also has an independently pinned raw inventory. Unknown metadata/code still fails. A new marker requires Installer25 before cleanup. Existing legacy installers refuse new metadata. Accept the exact clean official Umbrella6.7.97 tree as an input for Standard recovery, never a mixed/unknown tree. Preserve all saved preferences and accounts.

Candidate Build1.1.20 / Installer1.0.25, unpublished until authorized. Native Mac update test must use installed candidate packages and ordinary Kodi menus; do not hide failures by hotpatching the live profile. Apple UI testing remains pending a working screen/control path. Apple recovery is a separate incident: CoreDevice remove-existing-content=true affected the app container beyond its specified temporary directory; never use that flag again. The existing app was restored from a verified fresh backup; no Kodi reinstall/profile replacement.

Review ruling: metadata-only protection is insufficient because upstream Umbrella parses numeric versions. Add exact reviewed control.getUmbrellaVersion and cache.update_cache_version adapters, preserving all playback/network/source-selection code. Independently verify adapter hashes, normalize only those exact hashes for immutable historical code gates, and record the new raw full source inventory. Test migration and repository selection with no network.
