BlackLanturn 1.1.6 - Kodi 21.3 Omega

Update BlackLanturn Installer to 1.0.12 through the BlackLanturn Repository, then use the Builds catalog. Choose General for Fire TV / Android or Apple TV & Mac for compatible Kodi 21.3 installations. Kodi installation/signing is separate.

Included update
Controller 0.1.74 fixes UTF-8 Help decoding and displays the currently selected preview language preference. Preview candidates now require the selected title or an identity-scoped original-title alias at the beginning of the public YouTube title, followed by recognized trailer/season/year metadata. This rejects the confirmed American Horror Stories trailer incorrectly associated with American Horror Story. If public title evidence is unavailable or ambiguous, artwork remains visible. No YouTube search or arbitrary URL fallback is used. This conservative check can omit valid trailers whose marketing titles cannot establish the selected identity; it does not certify the exact season, publisher or spoken language. Existing repaired search/preloading, preview retry safety, artwork and watched/resume behavior remain.

TMDb Helper 6.17.9 includes empty-cache-1 and search-batch-1 (including successful-empty-search handling). Installer 1.0.12 verifies the complete reviewed Helper source before cleanup and preserves its Kodi per-addon auto-update protection. Reviewed future updates arrive through BlackLanturn releases. Deliberately replacing Helper or re-enabling its upstream auto-update opts out of this compatibility guarantee.

Preserving an existing setup
Keep a verified private recovery copy first. In Installer Settings > Install Settings, leave "Clean install: keep only selected accounts" off when retaining existing preferences. Select the relevant Keep options, including "Keep My guisettings.xml" for existing Kodi playback settings, "Keep My AdvancedSettings.xml", and Keep My Trakt/Debrid/Login Data. Check all intended preservation options before installing. Native playback components stay device-specific. Account-only clean mode intentionally resets other preferences; choose it only for a requested clean install.

Clean defaults included in both editions
- Cocoscrapers assigned and enabled for Umbrella playback.
- Automatic YouTube stream selection and enabled Helper watched indicators for authorized accounts.
- High artwork quality; tested 64MB/fixed400/buffermode4/chunk131072 video buffer defaults.
- Audio follows the current Kodi interface language (Kodi audio language "default"); subtitles use "forced_only". This does not independently detect the tvOS operating-system language.
- Existing player/Next Up controls, MPEG-DASH previews and edition-specific quality limits.
- Automatic cache/package/thumbnail cleanup remains off.
HDR/Dolby Vision filters, decoder choices and other hardware compatibility settings are not imposed globally on new downloaders. Preserve device-specific choices when updating an existing setup.
